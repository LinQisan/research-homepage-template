## 1. 基本の書式

段落は空行で区切ります。日本語の行は、改行しても空白なしでつながります。
**太字**、*斜体*、`コード`、[リンク](https://example.com)、[サイト内リンク](projects/example-project.html) が使えます。

## 2. コードブロック

コードブロックには自動で「コピー」ボタンが付きます。

```bash
npm run dev
```

## 3. 画像

画像は `public/images/` に置き、そこからのパスで書きます。

```figure images/projects/example-project/cover.svg | サンプルの概要図
キャプションを書きます。
```

## 5. 折りたたみ

```details 長いログやプロンプトを折りたたむ
ここに書いた内容は、クリックするまで隠れています。
```

ほかの部品（`compare`・`timeline`・`embed` など）の書き方は、`src/templates/blocks.js` の先頭のコメントを見てください。
